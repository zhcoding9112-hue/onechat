# Proposal

## Why

公会旗下 10 位签约主播目前只能依附第三方直播平台接一对一付费通话，平台抽走 20%–50% 的流水，且收入波动完全受制于平台的流量分发。这批主播自身已沉淀数千名可主动触达的粉丝，这部分需求完全可以绕开平台直接成交。

自建一条"粉丝 → 服务号 → 指定主播下单 → 付费 → 站外交付"的链路，即可把平台抽成转化为三方共享的空间：粉丝付得更少、主播到手更多、公会分得更多。本次变更的目标不是做规模，而是**在 4 周内用最小系统测出这条链路的真实转化率**，据此决定追加投入还是止损。

## What Changes

- 新建一套运行于微信服务号内的移动端 H5，承载粉丝端、主播端、运营后台三类界面，共用一套前端工程与后端服务。
- 粉丝经服务号网页授权登录，浏览主播目录，**指定某位主播**下单购买服务（情感倾听 / 情绪疏导 / 游戏陪玩），或直接发起打赏。
- 支付上线期采用**人工收款**：展示公会对公收款码，粉丝上传支付凭证，运营核对到账后确认订单。支付能力实现为可替换抽象，2–3 周后接入微信支付 JSAPI 时不改动业务逻辑。
- 订单具备完整生命周期与**超时处置**：主播未在时限内接单，订单自动置为已超时，通知双方并进入人工退款队列。
- 主播以同一 H5 的身份态登录，完成接单、标记完成、切换在线状态，查看只读收入记录。
- 服务目录、档位价格、分成比例全部后台可配；**分成比例在下单瞬间快照写入订单**，后续调整不影响历史订单分账。
- 分成站内只记账，不做站内提现，沿用既有线下月结流程。
- 交付**埋点与转化漏斗看板**，覆盖从关注服务号到 7 日复购的全链路节点，作为本次验证的判定依据。

### 不在本次范围内

以下功能明确不做。原因是它们均服务于陌生人之间的发现与匹配，而本产品的粉丝是指名找特定主播，不存在匹配问题：

榜单、心动墙、礼物与图鉴、盲盒抽奖、优惠券与券包、动态广场、站内即时通讯、试音选人、随机派单、搜索、业务分区、用户等级体系、收藏、留言板、公开评价。

另外明确不做：

- **自建实时音视频通话**。通话继续在站外发生，本系统不承载音视频流，因而不承担平台方的内容审核、实名核验与留存义务。
- **余额钱包**。采用单笔直付，钱包相关字段仅在数据模型中预留，不开放使用。
- **站内提现**。分成走既有线下月结。

## Capabilities

### New Capabilities

- `wechat-auth`: 微信服务号网页授权登录、用户身份建立与粉丝 / 主播 / 运营三类角色的识别与鉴权。
- `talent-catalog`: 主播目录与资料。列表、详情、标签、试听片段、在线状态展示，以及运营侧的主播增删改与上下架。
- `service-pricing`: 服务项目目录、档位定义、单价与分成比例的后台配置；按主播覆写价格；下单时的价格与分成快照取值。
- `ordering`: 订单生命周期。下单、待确认收款、待接单、已接单、已完成、已超时、已取消 / 已退款的状态流转，超时自动处置，运营人工处置入口，以及订单完成后的满意度回访（粉丝端不公开，主播可见自己的聚合评分，运营可见逐单明细）。
- `payment`: 支付能力抽象与人工收款实现。收款信息展示、支付凭证上传、运营对账确认、支付状态回写；为微信支付 JSAPI 预留同一套接口契约。
- `tipping`: 面向指定主播的自由金额打赏，复用支付与分成链路，独立于服务订单计量。
- `settlement`: 分成记账与月结。基于订单快照计算公会与主播分账，生成按主播、按周期的结算报表供线下月结使用。
- `talent-workspace`: 主播身份态工作台。待接单提醒、接单与标记完成、在线状态开关、只读收入与订单记录、自己的聚合满意度评分。
- `analytics-funnel`: 埋点事件采集与转化漏斗看板。覆盖关注服务号、打开 H5、浏览详情、提交订单、完成支付、主播接单、服务完成、7 日复购等节点，支持按主播与服务类型拆分，仅运营可见。

### Modified Capabilities

无。本项目为全新代码库，`openspec/specs/` 当前为空。

## Impact

- **新增代码库**：后端 Spring Boot 3 + MyBatis-Plus + Maven；前端 Vue 3 + Vite + TypeScript + Vant 4 + Pinia，运营后台以 `/admin` 路由并入同一前端工程。
- **数据存储**：新建 MySQL 8 库（用户、主播、服务与价格配置、订单、支付凭证、打赏、分成记账、埋点事件）；Redis 用于会话、超时队列与在线状态。
- **外部依赖**：微信公众平台（已认证服务号，网页授权）；后续接入微信支付商户平台。
- **外部阻塞项**（不占开发工期但决定上线日期）：域名 ICP 备案、服务号认证、微信支付商户号申请、公会与主播的分成比例与定价确定。
- **运营流程变更**：新增每日核对对公账户到账流水并在后台确认订单的例行工作；新增超时订单的人工退款处理。
