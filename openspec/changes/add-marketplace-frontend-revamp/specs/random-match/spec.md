# Spec Delta

## Purpose

为没有指定对象的粉丝提供一条随机匹配主播的下单路径，降低「不知道找谁」带来的流失。

## ADDED Requirements

### Requirement: 随机匹配主播

系统 SHALL 根据粉丝选择的条件随机选出一位可接单主播。候选集 MUST 只包含已上架且配置了对应服务的主播。匹配结果 MUST 为随机，MUST NOT 为固定顺序或轮询。本能力是随机派单，MUST NOT 以抽奖、开盒或任何射幸形式呈现，MUST NOT 收取与匹配动作本身绑定的费用。

#### Scenario: 成功匹配

- **WHEN** 粉丝选择服务品类并发起随机匹配
- **THEN** 系统从符合条件的主播中随机选出一位并展示其资料
- **AND** 提供直接下单入口

#### Scenario: 无符合条件的主播

- **WHEN** 当前没有任何主播满足所选条件
- **THEN** 系统提示暂无可匹配主播并建议放宽条件
- **AND** 不返回任何主播

#### Scenario: 重新匹配

- **WHEN** 粉丝对匹配结果点击换一位
- **THEN** 系统重新随机选出一位，并尽量避开刚刚展示过的主播

#### Scenario: 匹配不收费

- **WHEN** 粉丝发起任意次数的随机匹配
- **THEN** 系统不产生任何扣费、不消耗任何次数额度

### Requirement: 匹配条件与排除规则

系统 SHALL 支持按服务品类、性别与在线状态设定匹配条件，并支持排除已下过单的主播。条件 MUST 在发起匹配前由粉丝选择。

#### Scenario: 按性别匹配

- **WHEN** 粉丝将条件设为女生并发起匹配
- **THEN** 匹配结果只可能是性别为女的主播

#### Scenario: 排除已下过单的主播

- **WHEN** 粉丝勾选排除已下过单并发起匹配
- **THEN** 匹配结果不包含该粉丝此前下过单的任何主播

#### Scenario: 仅匹配在线主播

- **WHEN** 粉丝勾选仅匹配在线并发起匹配
- **THEN** 匹配结果只可能是当前在线的主播
