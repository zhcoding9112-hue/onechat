# Spec Delta

## Purpose

把声音作为挑选主播的主要依据，为不看重外形或尚未认准某人的粉丝提供一条以试听为核心的选人路径。

## ADDED Requirements

### Requirement: 按声音挑选主播

系统 SHALL 提供试音选人页，集中展示已上传试听片段的主播。列表项 MUST 以试听播放为主要操作，MUST 展示片段时长。

#### Scenario: 浏览并试听

- **WHEN** 粉丝打开试音选人页
- **THEN** 系统展示已上传试听片段的主播及各自片段时长
- **AND** 粉丝点击即可播放

#### Scenario: 同时只播一条

- **WHEN** 粉丝在一条片段播放中点击另一条
- **THEN** 系统停止前一条并播放新的一条

#### Scenario: 无试听片段的主播

- **WHEN** 某主播尚未上传试听片段
- **THEN** 该主播不出现在试音选人页

### Requirement: 发布试音需求

系统 SHALL 允许粉丝发布一条试音需求，描述想要的声音类型与服务品类。需求 MUST 设有有效期，过期后自动关闭。

#### Scenario: 发布需求

- **WHEN** 粉丝填写声音描述与服务品类并提交
- **THEN** 系统创建一条进行中的试音需求并对主播可见

#### Scenario: 需求过期

- **WHEN** 一条试音需求超过其有效期
- **THEN** 系统将其置为已关闭
- **AND** 主播不能再对其应征

#### Scenario: 同时只允许一条进行中的需求

- **WHEN** 粉丝已有一条进行中的试音需求并再次提交
- **THEN** 系统拒绝并提示先关闭已有需求

### Requirement: 主播应征试音需求

系统 SHALL 允许主播对进行中的试音需求提交应征，应征内容为其试听片段与一段留言。同一主播对同一需求 MUST 只能应征一次。

#### Scenario: 主播应征

- **WHEN** 主播对一条进行中的需求提交应征
- **THEN** 系统记录该应征并通知发布需求的粉丝

#### Scenario: 重复应征被拒绝

- **WHEN** 主播对同一条需求再次提交应征
- **THEN** 系统拒绝并提示已应征

#### Scenario: 粉丝查看应征并下单

- **WHEN** 粉丝打开自己需求的应征列表
- **THEN** 系统展示各应征主播的试听片段与留言
- **AND** 提供直接对其下单的入口
