# Spec Delta

## ADDED Requirements

### Requirement: 打赏结果对外展示

系统 SHALL 在打赏被确认收款后，将其计入主播的周期打赏榜并推送到首页跑马灯。对外展示 MUST 只包含主播昵称与打赏金额，MUST NOT 包含打赏人的任何身份信息。

#### Scenario: 打赏计入榜单与跑马灯

- **WHEN** 一笔打赏被运营确认收款
- **THEN** 该金额计入对应周期的主播打赏榜
- **AND** 该记录出现在首页跑马灯

#### Scenario: 未确认的打赏不展示

- **WHEN** 粉丝提交打赏但运营尚未确认收款
- **THEN** 该笔打赏不计入榜单，也不出现在跑马灯

#### Scenario: 退款后撤出展示

- **WHEN** 一笔已展示的打赏被标记退款
- **THEN** 该金额从榜单计算中扣除
- **AND** 系统不再将其推送到跑马灯

#### Scenario: 不泄露打赏人身份

- **WHEN** 任意粉丝查看榜单或跑马灯
- **THEN** 展示内容中不含打赏人的昵称、头像或任何标识
