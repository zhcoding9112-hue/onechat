# Spec Delta

## Purpose

让粉丝标记自己关注的主播并快速回到他们，降低复购时的寻找成本。

## ADDED Requirements

### Requirement: 收藏与取消收藏

系统 SHALL 允许已登录粉丝收藏与取消收藏任一已上架主播。同一粉丝对同一主播重复收藏 MUST 保持幂等，MUST NOT 产生重复记录。

#### Scenario: 收藏主播

- **WHEN** 粉丝在主播详情页点击收藏
- **THEN** 系统记录该收藏关系并将入口切换为已收藏态

#### Scenario: 重复收藏幂等

- **WHEN** 粉丝对同一位已收藏的主播再次提交收藏
- **THEN** 系统不新增记录，返回成功

#### Scenario: 取消收藏

- **WHEN** 粉丝对已收藏的主播点击取消收藏
- **THEN** 系统移除该收藏关系并将入口切回未收藏态

#### Scenario: 未登录时收藏

- **WHEN** 未登录用户点击收藏
- **THEN** 系统引导其完成微信授权登录
- **AND** 登录后自动完成本次收藏

### Requirement: 收藏列表

系统 SHALL 在个人中心提供收藏列表，按收藏时间倒序展示。已下架主播 MUST 仍保留收藏关系，但在列表中标记为暂不可约且不提供下单入口。

#### Scenario: 查看收藏列表

- **WHEN** 粉丝打开个人中心的收藏列表
- **THEN** 系统按收藏时间倒序展示其收藏的主播

#### Scenario: 收藏的主播被下架

- **WHEN** 已收藏的某主播被运营下架
- **THEN** 该主播仍在收藏列表中并标记为暂不可约
- **AND** 不展示下单入口

#### Scenario: 收藏为空

- **WHEN** 粉丝尚未收藏任何主播
- **THEN** 系统展示空状态与前往浏览的入口
