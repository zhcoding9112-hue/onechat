# Spec Delta

## ADDED Requirements

### Requirement: 发现入口来源归因

系统 SHALL 为每个发现入口（品类 Tab、人气店员、九宫格、运营横幅、试音选人、随机匹配、心动墙、动态广场、榜单、收藏列表、站内聊天）采集独立的入口事件，并在粉丝由该入口进入主播详情时记录来源。漏斗 SHALL 支持按入口来源拆分，以判断各入口的实际成交贡献。

#### Scenario: 记录入口来源

- **WHEN** 粉丝从人气店员横滑点击进入某主播详情
- **THEN** 系统记录一条进入详情事件，其来源标记为人气店员

#### Scenario: 按入口拆分漏斗

- **WHEN** 运营在看板按入口来源拆分漏斗
- **THEN** 系统分别展示各入口的进入详情、提交订单与完成支付人数

#### Scenario: 无来源的直接访问

- **WHEN** 粉丝通过主播分享的链接直接进入详情页
- **THEN** 系统将来源记为直接访问
- **AND** 该来源在拆分中单独成列

#### Scenario: 入口无数据

- **WHEN** 某入口在所选周期内没有任何事件
- **THEN** 看板中该入口一行展示为零，不隐藏该行
